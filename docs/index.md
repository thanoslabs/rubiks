**rubiks** is a lightweight interactive 3×3 Rubik's cube that runs as a static web page. You can scramble it, turn it, and solve it, and it celebrates when you do.

- [[usage]] covers controls, notation, scrambles, and how progress is saved.
- [[self-hosting]] covers running the container image or serving the static files yourself.

The app itself is at the root of this site, one level up from these docs.

> [!note]
> These pages are built from `docs/` by [nebula-md](https://github.com/thanoslabs/nebula-md) and deployed with the app whenever a merge to `main` touches `app/` or `docs/`.
